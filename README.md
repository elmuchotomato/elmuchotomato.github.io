# elmuchotomato.github.io

Landing page linking all of my live project sites.

**Live site:** https://elmuchotomato.github.io/

## Layout

```
index.html    the whole page: markup, styles and the list of sites
```

## Adding a site

The list is written by hand. Add an entry to the `<ul>` in `index.html`, using the
repo's name as the link, such as `/my-repo/`. There is no build step, and pushing
to `main` publishes the change.
